# End-to-end test: Zukai skills on a Google Cloud project (2026-11-17)

Tester role: an agent that follows the installed skill text literally, plus a plausible user
who answers its questions. Nothing in the repository was read or changed except this file.

## Setup

- Sample project (git repository):
  `/tmp/claude-0/-home-user-zukai-kobo/dfd23dcb-7283-57de-90e1-1d422710abbb/scratchpad/e2e-c/invoicing`
  - `infra/*.tf`: two Cloud Run services (`invoice-api`, `invoice-worker`), Cloud SQL on a
    private VPC network with a subnet and a serverless VPC access connector, a Pub/Sub topic
    with a push subscription, a Cloud Storage bucket, a Cloud Scheduler job, three Secret
    Manager secrets, service accounts and IAM bindings.
  - `services/invoice-api` (`@google-cloud/pubsub`, `pg`), `services/invoice-worker`
    (`@google-cloud/storage`, AWS SDK for S3 and SQS, `fetch` to an outside payment API).
  - `infra-aws/main.tf`: S3 bucket, SQS queue, IAM user.
- Install: `bash /home/user/zukai-kobo/install.sh --target claude-project --dest <project>`
  installed `zukai`, `zukai-revise`, `zukai-recook`, `zukai-sync` 2.3.0 under
  `<project>/.claude/skills/`. Only those copies were used from then on.
- Node v22.23.4. Renderer: Playwright with Chromium (`"renderer":"drawio-web"`); no draw.io
  desktop. `CLI` below is `node <project>/.claude/skills/zukai/scripts/bin/cli.mjs`.
- All paths below are relative to the sample project unless absolute.
